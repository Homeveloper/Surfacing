О проекте
Проект "Space Ship Game" - аркадный 3D-космосимулятор с системой выживания и процедурной генерацией
Это одиночная игра, в которой игрок управляет космическим кораблём, преодолевающим препятствия в бесконечно генерируемом космическом пространстве. Главная цель — пролетать сквозь череду космических врат, избегая столкновений с астероидами и сохраняя управляемость при увеличивающейся скорости.

Ключевая особенность игры — чанковая генерация уровней. Мир создаётся из заранее подготовленных модульных блоков (чанков), соединённых друг с другом. Каждый из них имеет уникальную форму (прямой, с поворотами, извилистый), создавая неповторимые траектории.

Игровой процесс сопровождается следующими механиками:
- Вид от третьего лица - камера расположена позади корабля
- Постоянное движение вперёд - игрок управляет лишь направлением
- Инерция при поворотах и динамическое увеличение скорости каждые 30 секунд
- Щитовая система - при столкновении с астероидами теряются очки щита (до 100%)
- Астероиды трёх типов - малые, средние и крупные с разным уровнем урона
- Разрушаемые препятствия - взрываются при контакте с эффектами частиц и звуком
- Визуальные ориентиры - светящиеся стрелки указывают путь к выходу чанка
- Если выходные врата не видны - появляется восклицательный знак, указывающий их расположение

Управление:
A - поворот налево
D - поворот направо


Внимание!
В игре два режима это:
- Pilot mode
- Pulse mode

Pulse mode реализована для миографической системы Callibri Muscle Tracker
В главном меню нужно перейти в "Settings"и выбрать "Pilot mode", затем можно уже играть.
